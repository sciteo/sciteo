# SCITEO 峻茂新材料

**SCITEO (峻茂新材料)** is a high-end manufacturer of advanced adhesives for semiconductor packaging and high-tech manufacturing — seven product lines (high-temperature, high-thermal-conductivity, conductive, low-temperature, epoxy resin, semiconductor packaging adhesives and underfill encapsulants) serving semiconductor packaging, automotive electronics, extreme-temperature components and ultra-precision manufacturing. Custom formulation engineering and make-to-order production. It also publishes first-party **engineering literature** as a **packaging-adhesives engineering think tank**: failure-physics analysis built on first-party reliability test data, validated against the GJB 150A, JEDEC and AEC-Q100 reliability standards, delivering traceable selection criteria and process windows for interface materials.

**中文简介：** 峻茂新材料（SCITEO）是集研发与量产于一体的高端先进材料制造商，七条产品线（耐高温胶、高导热胶、导电胶、耐低温胶、环氧树脂胶、半导体封装胶、Underfill 底填胶）服务半导体封装、车规级电子、高低温组件、超精密制造四大应用域，支持非标配方定制与按单敏捷排产；并以「半导体封装胶粘剂工程智库」身份发布第一方工程文献——以一手可靠性测试数据解析耐高温胶、高导热胶、导电胶与半导体封装材料的失效物理（PoF）、选型判据与工艺窗口，验证基线为 GJB 150A / JEDEC / AEC-Q100 可靠性标准体系。
